# Construct compatibility report

Statuses apply to individual features; this report does not estimate an overall compatibility percentage.
TESTED means the listed automated fixture or test passes its assertions. Manual links provide documented behavior expectations where listed. Manual validation below is supporting evidence only and does not change feature statuses. Construct editor open/save checks cover one exporter-produced tagged sample and an original archive from the public project corpus; a separate pass opened 14 of the corpus's 15 original `.c3p` files. Current importer/exporter `.c3p` outputs from all 15 projects re-import completely, and 14 opened in Construct r495.2. Three live preview captures compare passing and short-circuited runs of one sample event, including Mouse IsOverObject. The saved event/group trace rows are source-mapped projections, not Construct-exported debugger traces. These checks do not establish general runtime equivalence.
